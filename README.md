# Generation of AI Powered Synthetic Users for Product Research

## Overview

This project is an AI-powered platform that generates synthetic user personas to help researchers explore product ideas and collect simulated feedback. A researcher provides product details, target audience, and research objectives. The platform generates personas and supports survey-based research, persona interviews, insight extraction, product preference scoring, and PDF report generation.

**Important:** Synthetic personas and their responses are AI-generated simulations. They are useful for early exploration, but they do not replace research with real users or represent statistically valid customer evidence.

## Features

- **Synthetic Persona Generation:** Generate five personas based on the product and target audience.
- **Survey Mode:** Collect simulated responses from the generated personas.
- **Interview Mode:** Ask questions to a selected persona while retaining conversation history.
- **Insight Extraction:** Summarize themes, sentiment, agreement patterns, behavioral trends, pain points, and recommendations from survey responses.
- **Product Validation Scoring:** Generate a preference score from 0–100 with reasoning and a Yes/Maybe/No decision.
- **Research Dashboard:** View keyword-based theme clusters, approximate sentiment indicators, persona response excerpts, and validation scores.
- **PDF Research Report:** Download a report containing research responses, insights, validation scores, and limitations.
- **Local LLM Support:** Uses Ollama with the Qwen3 model for local generation.

## Workflow

1. Enter the product description, target audience, and research objective.
2. Generate synthetic personas.
3. Run a survey or interview a selected persona.
4. Extract insights from survey responses.
5. Generate product preference scores and decisions.
6. Review the dashboard and download the PDF research report.

- Python 3.10 or later recommended
- Ollama installed and running
- The Qwen3:8B model downloaded in Ollama

## Setup and Run

### 1. Clone the repository

```bash
git clone https://github.com/himanshukumar-aiml/synthetic-user-platform.git
cd synthetic-user-platform
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install Python dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Install and prepare the local model

Install Ollama from its official website, then download the model:

```bash
ollama pull qwen3:8b
```

Make sure Ollama is running before launching the application.

### 5. Start the Streamlit application

```bash
python -m streamlit run frontend/app.py
```

If your local project uses a different entry-point file, run the Streamlit command for that file instead.

## Limitations

- Personas and responses are generated by an AI model and may contain inaccuracies or unsupported details.
- Dashboard theme and sentiment indicators are approximate keyword-based analyses.
- Product preference scores are model-generated estimates, not measured purchase intent.
- Results should be validated with real users before making business or product decisions.
